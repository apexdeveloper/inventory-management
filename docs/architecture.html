Factory Inventory Management System

Architecture overview: a Vue 3 single-page application backed by a Python FastAPI service that serves in-memory mock data loaded from JSON files. There is no database and no authentication.

Data Flow

How a filter change on the page becomes updated charts and tables.

  1. User changes a filter Time Period, Warehouse, Category, or Order Status in the FilterBar.
    components/FilterBar.vue
  2. Shared filter state updates Filter refs are module-level singletons, so every view sees the same values.
    composables/useFilters.js
  3. View watcher fires Each view watch()es the filters it cares about and calls its loader.
    views/*.vue
  4. API client builds the request getCurrentFilters() maps state to warehouse, category, status, month; values of all are dropped.
    src/api.js
  1. FastAPI filters in memory apply_filters() matches warehouse/category/status; filter_by_month() handles YYYY-MM or quarters like Q3-2025.
    server/main.py
  2. Aggregate and validate Summary endpoints compute totals; Pydantic models validate list responses.
    server/main.py
  3. JSON response Axios resolves; the view assigns the result to raw refs such as allOrders or inventoryItems.
    views/*.vue
  4. Computed properties re-render Derived data (KPIs, chart series, sorted tables) is recomputed and formatted per locale/currency.
    views/*.vue, utils/currency.js

State management

No Vuex/Pinia. Shared state lives in module-level refs inside composables, which makes them app-wide singletons. Raw API data is held in refs; everything shown is derived through computed.

Internationalization

useI18n resolves dotted keys like nav.dashboard against locales/*.js, falls back to English, and persists the locale in localStorage. Japanese locale also switches currency to JPY.

Mock user

useAuth provides a hard-coded, locale-aware user profile and seed tasks. There is no real login.

Observations

Frontend calls endpoints that don't exist api.js defines task (GET/POST/PATCH/DELETE /tasks) and purchase-order (/purchase-orders) calls, but server/main.py has no such routes. These requests return 404; App.vue still shows the mock tasks from useAuth.
Backlog view is unreachable views/Backlog.vue exists but is not registered in the router in main.js. Backlog data surfaces only on the Dashboard.
Inconsistent API access Reports.vue calls axios with a hard-coded URL instead of going through api.js. The API base URL is hard-coded in both places rather than configured via environment.
Duplicated quarter logic /reports/quarterly re-implements quarter detection with string checks instead of reusing QUARTER_MAP; both are fixed to 2025.
Demo-grade by design Open CORS (allow_origins=["*"] with credentials), no authentication, no persistence, and substring-based date matching are fine for a workshop demo but would need rework for production.
